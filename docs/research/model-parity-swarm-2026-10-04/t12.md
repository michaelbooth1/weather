## Rules
Four rules were registered in C:\swarm\registry.jsonl before the first score: two candidates and two
controls.

**t12-r1** (fixed alpha=+0.5, zero fitted parameters):
1. At snapshot t, take the revision step: the latest captured nws_grid_high_raw minus the value it
   replaced. Only same-market-day snapshots with captured_at <= t are used.
2. Translate served by 0.5 times the step, in degF, on the integer-degree grid:
   - band mass is spread uniformly over the degrees of the band;
   - tails are edge points;
   - fractional shifts use linear interpolation;
   - the edges clip.
3. Apply the floor and renormalise.
4. Rows with no revision yet fall back to served.

**t12-r2**: as r1, but alpha is fitted on the before stratum only.
- Fit: grid -1..+1 in steps of 0.25, minimising floored band Brier on before rows with a revision. The fit
  gave **alpha=+0.25**.
- The before-stratum Brier curve is nearly symmetric, which already pointed to smoothing rather than
  direction:

  | alpha | Brier |
  |---|---|
  | -0.5 | 0.621 |
  | -0.25 | 0.5931 |
  | 0 | 0.5953 |
  | +0.25 | 0.5913 |
  | +0.5 | 0.620 |

**t12-c1** (control): r1 with alpha=-0.5, so the shift goes against the revision.

**t12-c2** (control): 0.5*shift(+0.5*|step|) + 0.5*shift(-0.5*|step|). This is a direction-free blur on
the same rows as r1.

## Point-in-time statement
- The only non-served input is nws_grid_high_raw as production captured it at each snapshot. Its
  availability time is nws_grid_fetched_at.
- h.assert_point_in_time(fetched_at, captured_at_utc) passed for every non-null value: 0 late, median lag
  0.1 min.
- nws_grid_updated_at <= captured_at on every row (median 176 min earlier).
- The revision at t uses only snapshots of the same market-day with captured_at <= t.
- No market prices, mids or books are inputs (rule 2).
- winner and settlement_high are not inputs (rule 3). Labels were read only for the r2 fit and the
  diagnostic, and only for before_20260823 (asserted in code).
- The harness applies the rule-4 floor.
- Primary estimand: all rows, with served as the fallback (rule 6).
- No hour gate is used (rule 8).
