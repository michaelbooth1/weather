## Rules (registered in C:\swarm\registry.jsonl before the first score; full text there)

**Diurnal shape.** It comes from IEM METAR history with local dates <= 2026-07-31 (routine + SPECI, COR
excluded, tmpf, days with >= 18 obs). For each obs, ratio = (max of the obs at or after it that day - T) /
(day max - running min up to that obs), kept when the denominator is >= 2 F. r(station, target month,
local half-hour) is the median ratio over months {m-1, m, m+1}, smoothed over +/-1 bin and clipped to
[0, 1.5].

**At snapshot t.** T_now is the latest obs, Tmin the day's running min and M the day's running max, all
from PIT METAR. G is the captured guidance high. A = max(G - Tmin, 0) and **P = max(M, T_now + r*A)**.

| id | G | distribution |
|---|---|---|
| t15-r1 | forecast_high | Served pmf (floor-masked, on integers) shifted so its mean equals P. Served's shape is kept. Zero fitted parameters beyond the history r table. |
| t15-r2 | forecast_high | Discretised Normal(P, sigma_block), with sigma = RMS(settlement - P) on the **before stratum only**. Sigma by block: 00-05 2.86, 06-09 3.53, 10-12 3.08, 13-16 2.19, 17-23 0.27 F. |
| t15-r3 | nws_grid_high | As r1. |
| t15-r4 (control) | forecast_high | As r2, but P = max(M, G) with no diurnal shape and the same coverage. This is a decomposition diagnostic. |

Uncovered rows fall back to served (rule 6): no same-day METAR yet, or no G. The harness applies the
rule-4 floor to every candidate.

## Point-in-time statement

- **METAR.** An obs enters at snapshot t only if available_utc = valid_utc + 10 min <= captured_at_utc,
  using the A-IEM availability basis in `C:\swarm\data\iem\metar\MANIFEST.json`. COR reports are excluded
  and the obs's local date equals the target date. `h.assert_point_in_time` passed for every station.
  IEM 1-/5-minute data are not used. The 11 parquet files matched their manifest sha256 at read time
  (00:48 local), and the manifest was not yet frozen.
- **Guidance.** forecast_high and nws_grid_high are captured snapshot features. In 0 rows was
  nws_grid_fetched_at or nws_grid_updated_at later than captured_at_utc.
- **Diurnal table.** It uses history <= 2026-07-31 only, asserted in code.
- **Labels.** settlement_high is read only for before-stratum rows, to fit the r2/r4 sigma (5 numbers) and
  for MAE diagnostics (rules 3 and 7). No label, winner or market value enters any candidate, and no
  market input is used.
- **Rule 8.** No hour gate is chosen for NBM/NBP guidance. The per-block sigma uses the harness's fixed
  blocks. r(h) is a history-fitted shape, not a gate.

## Serveability

**Class: needs new capture**, plus a static-parameter serving stage. **Not zero-parameter**: the rule uses
a history-fitted r table and 5 sigmas fitted on the before stratum.

- **Capture.** Each snapshot needs the latest PIT METAR obs per station: current tmpf, plus the local-day
  running min and max over routine + SPECI, non-COR. Cadence is hourly plus SPECI. It is free (NWS/IEM
  METAR), the disk cost is negligible, and the effective lag is valid + about 10 min.
- **What production already has.** It captures high_so_far and trusted_current_max. By 17-23 these match
  the METAR running max (F3: mean -0.01 F, 1.6% of rows differ by >= 1 F). So the 17-23 part could
  probably be served from captured fields plus the current temperature. Not scored here; it would need its
  own registration. Before about 10:00 high_so_far does not equal the METAR running max, so morning
  inputs require the new capture.
- **Overlap.** The 17-23 effect is the same mechanism as T1, so a deep dive should treat T1 and T15-r2
  17-23 as one family, not two independent leads.

## Caveats for refuters

1. In 17-23 sigma = 0.27 F puts nearly all mass on round(P). Its sensitivity to the METAR availability lag
   (+1 h/+2 h) and to tmpf versus T-group rounding is untested here.
2. The before stratum is in-sample for sigma (5 parameters). The from stratum is out-of-sample for sigma,
   but it was previously read (rule 7), so it is a development read.
3. The morning "LEAD" belongs to the r4 control's mechanism, a forecast_high-centred Normal with a
   per-block fitted sigma. That overlaps the closed recalibration/sharpening thread, so it should not be
   counted as T15 evidence. The registry denominator still includes r4.
4. The diurnal r table medians are 0 from about 17:00 at most stations, so after the peak P = M almost
   always.
