## Skeptic pass

- **S-01 (D3-01).** *Argument against:* Polymarket might never emit negative labels, or `bin_value` in token rows
  might not be used for joins because they key on `clob_token_id`. *Refutation:* `mm_paper_scoring.py:230`,
  `market_microstructure_features.py:119-126,544` and `execution_tape_markout.py:387` all read `bin_value`
  numerically. The Celsius markets include northern cities, and 95b itself was raised as Q-09 for exactly this
  label shape (`tests/market/test_native_band_scoring.py:14-17` uses `-5 °C or below`). *Second argument:*
  `parse_temperature_band` returns None on unparseable text where the old code returned a guessed eq value.
  *Answer:* keep the old digit fallback only when the canonical parser returns None, and log it. The row
  stands as a refactor.
- **S-02 (D3-02).** *Argument against:* the explicit columns are always present, so the fallback never runs.
  *Answer:* this is not verified for every row source (`band_key_text` rows come from multiple producers). The
  fix is cheap and parity-neutral for positive values. The row stands, reach confidence med.
- **S-03 (D3-03).** Display-only, no data effect. Kept as document.
- **S-04 (D3-04).** *Argument against consolidating the text encoders:* `lte_{v}c`, `:g` and `.1f` strings
  are persisted in tapes, sidecars and replay reports; one encoding would silently break joins with
  historical files. *Upheld.* Downgraded: consolidate only the tuple producers (which feed the encoders) onto
  `temperature_band_key`, and document the encodings as frozen formats.
- **S-05 (D3-05).** *Argument against:* the two verifiers may be intentionally different, a light one for
  release loaders and a strict one for qualification. *Answer:* the strict checks are the ones the release
  loader needs (`residual_distribution_release.py:399-406` passes both extra parameters), and the contract
  module's stated purpose (`point_in_time_contract.py:1-7`) is to host exactly this verifier. Porting the
  strict version into the contract keeps behaviour. The row stands. Requires a parity test: both old
  functions must raise the same `ContractViolation` codes on a shared fixture set.
- **S-06 (splits).** *Argument against:* splits churn fingerprints and the D3-01/05 fixes are worth more.
  *Answer:* the order is D3-05 first (it shrinks D3-06/07 and moves them off the capture path), then roll-free
  splits (D3-08, D3-09), and last the loop-imported ones (D3-12). Facades keep every `-m` entry and public
  import, so `test_documented_python_module_targets_exist` still passes.
- **S-07 (D3-10/11/13).** Live trading is paused, maker code is moving to `maker_core`, and Release #1 is off
  the critical path. Splitting code that is about to be superseded or parked is waste. Downgraded to document.
- **S-08 (D3-14).** *Argument against:* tests monkeypatch `module.utc_now`, and importing the name breaks
  that. *Refutation:* `from weather.time import utc_now` binds a module attribute, so `monkeypatch.setattr(module, "utc_now", …)`
  still works. The str-returning copies must not become the datetime helper, or JSON rows change type.
  Consolidation passes for the 32 datetime copies only.
- **S-09 (D3-15).** Upheld keep: rounding differs, and the model path is parity-bound.
- **S-10 (D3-16).** *Argument against bulk consolidation:* moving 51 in-place writers to `os.replace` on
  Windows fails with PermissionError while a reader holds the file. Machine-local notes also record that a
  reader using `ReadLines()` has blocked writers in production. *Upheld.* Downgraded to document plus a
  count-freezing ratchet.
- **S-11 (D3-17/18).** *Argument against:* a per-module ceiling blocks urgent quiet-window fixes. *Answer:*
  let the ceiling live in `OWNERSHIP_NOTES` as `max_lines`, allow a reviewed bump in the same commit (as now),
  and make the default action "split" rather than "extend the list". The rows stand.
- **S-12 (D3-19).** *Argument against:* splitting test_daily_refresh changes the bounded-suite file selection.
  *Answer:* the bounded suite takes explicit file lists (`scripts/ops/bounded_worktree_test_suite.ps1`), so
  the list needs a same-change update. The row stands, workstation-only.
- **S-13 (D3-20/21).** Touches every capture loop, so the benefit is structural rather than behavioural.
  Kept at refactor/document with an owner decision.
- **S-14 (D3-22).** `TRANSITIONAL_PACKAGE_EDGES` requires an edge to be observed (`stale_transitional`
  assert, `test_import_architecture.py:1227`). Retiring an edge therefore also means deleting it from the
  set in the same change, otherwise the test fails. The row stands with that note.
- **S-15 (D3-23).** The facade exists on purpose (docstring). The inversion keeps its purpose and removes
  the conduit. The row stands.

## Proposed ratchets

1. **Per-module ceiling:** add `max_lines` to each `OWNERSHIP_NOTES` entry. The test asserts
   `lines <= max_lines`, and a reviewed bump must change the note in the same commit. This closes F3 and
   D3-17.
2. **Test-file size audit:** extend `build_module_size_audit` to `tests/` at 3,000 lines with its own
   allowance, and to `src/maker_core` at 2,000.
3. **Signed band parsing:** fail when any file other than `units.py` both mentions `below|higher|above` and
   calls `re.findall(r"\d+"` or `re.findall(r"-?\d+"` (allow-list the two display sorters). This would have
   caught D3-01 and D3-02.
4. **Private helper count freeze:** following `test_temperature_rounding_uses_canonical_helper`, freeze the
   counts of `def (_)?utc_now`, `def (_)?write_json`, `def _read_json`, `def *band_key*` and `def _parse_utc`
   in `src/weather`, allowing them only to fall (F4 recommendation, still unimplemented).
5. **One verifier per contract:** fail if a top-level public `verify_*` name defined in
   `point_in_time_contract` is redefined elsewhere in `src/weather` (D3-05).
6. **Import checks for top-level modules:** treat `src/weather/*.py` as a pseudo-package `root` in
   `observed_package_edges` and forbid root→reporting/operations except for an explicit list. This covers F6
   and D3-23.
7. **Transitional edge weight pin:** record the file count per transitional edge and allow it only to fall
